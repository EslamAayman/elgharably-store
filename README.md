# الغرابلي ستور

افتح `index.html` في المتصفح. المتجر واجهة كاملة قابلة للتجربة تشمل: تصفية المنتجات، سلة، حجز، وخطوة إتمام الطلب.

قبل الإطلاق: استبدل رقم واتساب التجريبي `201000000000` في `app.js` برقم المتجر الحقيقي. خيار «دفع إلكتروني» يوضح التدفق فقط؛ يلزم ربط بوابة دفع حقيقية (مثل Paymob) بمفتاح المتجر وخادم خلفي آمن قبل تحصيل أي دفعات.
